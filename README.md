# Entregable 2 Programación Avanzada

Simulador concurrente de un restaurante desarrollado en Java para **Programación Avanzada**.

Cada actor del restaurante —cliente, mozo, cocinero y cajero— es un hilo que corre en paralelo y se comunica con los demás mediante colas bloqueantes.

## Integrantes

- Juan Martín Berglavaz
- Camila García

## Requisitos

- **Java 17** o superior
- **Maven 3.8+**

## Cómo ejecutar
1. Abrir `src/main/java/entregable2/restaurante/Main.java`.
2. Hacer clic en el **botón ▶ verde** al lado del método `main`. 
3. Se abre una ventana con el monitor del restaurante en tiempo real.
